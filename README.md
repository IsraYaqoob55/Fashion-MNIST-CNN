# Fashion-MNIST Classification Using CNN

## Project Overview

This project implements a Convolutional Neural Network (CNN) using TensorFlow and Keras to classify grayscale clothing images from the Fashion-MNIST dataset into 10 categories.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Dataset
Fashion-MNIST contains 70,000 grayscale images of clothing items across 10 categories, with 60,000 training images and 10,000 test images.

## Objective
Train and evaluate a CNN model for recognizing different categories of fashion products.

## How to Run
1. Open `CNN_Fashion_MNIST.ipynb` in Google Colab.
2. Install any required dependencies.
3. Run all notebook cells in order.
4. Review the training results and evaluation metrics.
